# Snake Arena · AI 贪吃蛇赛场

这是一个可以在本机运行的多人贪吃蛇比赛项目。AI 蛇由独立程序控制，也可以加入一条本地玩家操控的蛇；游戏按固定回合数运行，支持比赛回放和多场排行榜。

## 运行

需要 Node.js 20 或更新版本。项目只使用 Node.js 内置模块，**不需要安装 npm 依赖**。

在本目录打开 PowerShell 或命令提示符，运行：

```powershell
node src/server.js
```

然后在浏览器打开 <http://127.0.0.1:4173>。关闭终端中的服务可按 `Ctrl+C`。Windows 用户也可以双击 `start.cmd`。

网页打开后会自动计算并播放一场比赛。可以暂停、逐回合移动、调速、拖动进度条、查看历史回放，也能运行多场锦标赛。

## 亲自参赛

网页上方的「参与方式」选择「亲自参赛」，再点「开始新比赛」，即可在现有 AI 选手之外加入一条玩家蛇。使用**方向键或 W、A、S、D**转向，空格暂停或继续；棋盘下方也有可点击的方向按钮和回合速度设置。玩家蛇头有白色描边，积分榜中标有「你」。碰撞、吃苹果和重生都遵循同一套规则。

选择「只观战」再开始比赛，会继续使用原来的 AI 自动对战和回放流程。完整打完的玩家比赛会自动保存到历史回放；点「结束本局」会停止当前比赛，已进行的回合仍可在当前页面查看，但不会存为完整回放。当前默认 4 名 AI 加入玩家后共 5 条蛇；手动模式最多支持 5 名 AI 加 1 名玩家。

页面底部的「模型一对一测评」可以选择 `bots/` 中的两份策略程序，按固定种子交换位置比赛，并逐局查看比分、胜者、死亡、苹果数、错误和耗时。100 个种子对应 200 局，综合成绩会显示独胜率和双方平均数据；完整报告写入 `evaluations/reports/`。

在终端批量比较 8 场（可自行替换场数和起始种子）：

```powershell
node src/tournament.js 8 20260928
```

完整单场回放和锦标赛结果分别保存到 `replays/` 目录。

## 让 AI 策略逐版挑战

候选策略可以先对战均衡选手，通过后再挑战上一版冠军。专用评测命令会在同一种子下交换双方位置各打一局，保存逐局报告和败局回放：

```powershell
node src/evaluate.js --candidate bots/my_bot.js --against baseline --seeds 10
node src/evaluate.js --candidate bots/my_bot.js --label my_bot_v01 --promote
```

晋级的策略会被保存为不可变的版本快照。完整迭代步骤、晋级标准和历史版本对战方法见 [EVALUATION.md](EVALUATION.md)。

## 加入 AI 选手

`roster.json` 是参赛名单。复制 `bots/template.js` 为新的策略文件，修改其中的决策函数，然后在 `roster.json` 添加一项：

```json
{ "name": "我的模型", "command": "node", "args": ["bots/my_bot.js"] }
```

名单支持 2～6 条蛇。每个参赛程序作为独立的常驻进程运行，一行输入对应一行输出。程序可以跨回合保留自己的内存；每场比赛会重新启动。JavaScript 模板可以直接运行。完整格式见 [BOT_PROTOCOL.md](BOT_PROTOCOL.md)，可复制给不同模型的统一要求见 [AI_PROMPT.md](AI_PROMPT.md)。

接口允许其他语言：安装对应运行时后，把 `command` 和 `args` 改为启动该语言程序的命令即可。例如安装 Python 后，可参考 `bots/python_template.py`。当前机器上没有检测到 Python，因此 Python 模板未在本机执行验证。

## 当前规则

默认 20×20 棋盘、4 条蛇、5 个苹果、500 回合。苹果被吃掉后在空格补充。吃苹果得 1 分并增长 1 节；碰撞会使体长和当前积分重置，下一回合结束时在安全空位重生。左右和上下边界相连。所有选手同时行动；同格撞头和交换蛇头位置时双方死亡。终局以当前分数最高者获胜，同分平局。完整判定顺序见 [RULES.md](RULES.md)。

默认名单中的 4 条蛇是**手写的演示策略**，用于验证和展示接口。项目还附带 `bots/model-a-v20.js` 和 `bots/model-b-v78.js` 两份经过迭代的策略程序，可以在「模型一对一测评」中选择；它们不是模型权重，也不会调用在线 AI 服务。策略版本和公开评测结果见 [内置策略说明](docs/BUILTIN_MODELS.md)。

要让其他 AI 编写参赛策略，请把同一份 `AI_PROMPT.md` 和规则文档交给它们，保存生成的程序到 `bots/`，先在一对一测评中试跑。要把策略加入多人默认名单，再按 `roster.json` 中的格式登记。程序接口和启动要求见 [BOT_PROTOCOL.md](BOT_PROTOCOL.md)。

## 项目结构

| 位置 | 用途 |
| --- | --- |
| `src/engine.js` | 纯游戏规则与状态转换 |
| `src/runner.js` | 启动选手程序、运行单场和锦标赛 |
| `src/server.js` | 本地网页和比赛接口 |
| `src/tournament.js` | 命令行锦标赛 |
| `src/evaluate.js` | 双蛇配对评测和冠军晋级命令 |
| `bots/` | 选手模板和演示策略 |
| `bots/model-a-v20.js`、`bots/model-b-v78.js` | 两条内置迭代策略 |
| `web/` | 棋盘、积分、回放和排行榜 |
| `test/` | 核心规则测试 |
| `replays/` | 本机自动保存的比赛结果，不纳入版本库 |
| `evaluations/` | 本机评测报告和版本快照，不纳入版本库 |

运行规则测试：

```powershell
node --test
```

## 运行选手代码的边界

比赛器限制每步响应时间，超时或崩溃的选手将持续沿原方向移动。它**不是操作系统级沙箱**；本机版本只运行自己编写或检查过的程序。若以后接收陌生人的参赛代码，应增加容器隔离与网络、文件访问限制。
